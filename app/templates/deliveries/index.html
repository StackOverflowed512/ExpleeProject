What the outcomes mean
Dry run (simulated)
Recorded only. No mail server was contacted and nothing was sent.
Sent
The mail server accepted the message. That does not guarantee inbox placement.
Failed
Nothing was delivered. The draft can be sent again.
Uncertain
The connection failed after the message was transmitted, so it may have been accepted. Email cannot guarantee exactly-once delivery, so a person must check before anything is sent again.
Manual resolution
An operator checked the mailbox or server logs and recorded the verified result.
In progress
A send is running now, or was interrupted and is waiting for a person.
